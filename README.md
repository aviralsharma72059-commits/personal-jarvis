# Personal JARVIS (Android, Kotlin, Compose)

Builds in the cloud with GitHub Actions. No API key is stored in this repo:
open the app, tap the gear icon and paste your Claude API key (kept encrypted on the device).

- Actions > "Build Debug APK" > Run workflow > download `jarvis-debug-apk`.
- Optional: Actions > "Add Gradle Wrapper" > Run workflow (commits gradlew + jar).

# Personal JARVIS (Android, Kotlin, Compose)

An intelligent Android voice assistant powered by Claude AI.

Builds in the cloud with GitHub Actions. No API key is stored in this repo.

Open the app, tap the gear icon and paste your Claude API key.

## Build APK
1. Open GitHub Actions.
2. Select Build Debug APK.
3. Click Run workflow.
4. Download jarvis-debug-apk.

## Features
- Voice Commands
- Android App Control
- Claude AI Integration0
